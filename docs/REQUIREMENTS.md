# Requirements

P0: responsive dark shell, business and engineering navigation, command centre, collapsible copilot; label illustrative metrics. P1: synthetic client data, real CSV/Excel/JSON ingestion, relational SQL model, raw/validated/business layers, validation and reconciliation, execution logs. P2: operational views, reporting, optional grounded AI assistant. No real client data or credentials. Public copy must omit employment messaging.

Acceptance: metrics traceable to data, invalid records quarantined, repeat imports idempotent, failures visible, mobile layout usable. Proposed scope subject to refinement.
