# Preview contract v1
Generate with python -m pipelines.export_preview snapshot.json from mac-data-engineering.
Top-level schema_version=1, synthetic=true, mode=generated_snapshot, summary, records, reconciliation.
Summary contains batch_id, accepted, rejected, entity_counts and order_value_cents. Records are validated Silver rows grouped by the ten canonical entities. Reconciliation contains invoice balances, outstanding_cents, overpaid_cents, stock and exceptions. Stock count 88 is a synthetic observation, opening zero; not a live count. Currency is integer EUR cents. Order value is not recognized revenue. Static preview has no live refresh. Missing or invalid snapshot must display unavailable, not fabricated metrics. MAC-05 connector adapter registers ten CSV sources; combined backend and data-engineering checkout required. No live HTTP used in exporter.

MAC-10 adds monitoring (required by current frontend): sources (last read health), batches (latest status per ID), rejections (zero-based ordinal), counts (Bronze/Silver/quarantine), audit (derived batch events). Fresh temporary database per export; no longitudinal or immutable audit history. Timestamps are actual UTC execution timestamps.
